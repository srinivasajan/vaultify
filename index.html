How Vaultify Works

A deep dive into the security model, format design, and offline capabilities.

AES-256-GCM Encryption

Every file is encrypted using AES-256-GCM — the same military-grade standard used by banks and governments. Without the exact password, the data is mathematically impossible to read.

PBKDF2 Key Derivation

Your password is never stored. It's stretched into a 256-bit key using PBKDF2 with 250,000 iterations + a random salt, making brute-force attacks extremely slow.

Custom Extensions

The extension (.yowtf, .iamboss, etc.) is just a human label — it doesn't change security. Inside, every vault file has the magic bytes VLTFY so Vaultify always recognizes it.

Zero Server Storage

All encryption/decryption runs in your browser using the Web Crypto API. Nothing is sent to any server. Your files never leave your device. Log your network tab — you'll see zero uploads.

Offline Capable

Save this HTML file to your computer. Open it without internet. Everything still works because all logic is embedded in this single file — no CDN calls except Google Fonts on first load.

Format Integrity

Even if someone knows the custom extension and sees the file, they cannot read it. The ciphertext is completely opaque without the password. AES-GCM also detects tampering.

Forget Your Password?

There is no password recovery. No reset. No backdoor. If you lose your password, the data is permanently unrecoverable — by design. Store your password in a password manager.

Large Files

This runs in the browser — very large files (>500 MB) may be slow or hit memory limits depending on your device. For best results, keep files under 200 MB.
